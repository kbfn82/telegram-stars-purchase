## 星星在 Telegram 里能买什么

Stars 是 Telegram 的内部计费单位，余额挂在账号上，换手机、重装应用都还在。花得出去的地方集中在数字商品和服务：机器人与迷你应用里的付费功能、游戏内购、频道付费内容、给作者的 Star 打赏、Telegram Gifts 礼物，还可以用来在开启了付费消息的群组里发言，或者给朋友送一份 Premium 订阅。实体商品买不了，也不能转到别的钱包或平台。

花钱买的星星和赚来的星星是两回事。买进余额的星星只能消费，官方条款写明不得出售、提现或转让；只有频道主、机器人开发者这类靠创作赚到星星的人，才有资格把它换成 Toncoin。

## 三条购买路径：贵在哪，星星进谁的账户

官方条款列出的入口是 iOS 和 Android 应用内购，以及直装版 Android、Web 版和桌面版里的官方机器人。Fragment 在 Telegram 的 API 文档里被列为替代购买方式，用 TON 结算。第三条是第三方机器人或网页服务，它们先从官方或其他渠道拿到星星，再按自己的汇率卖给你。

| iOS / Android 内购 | 商店抽成 15%–30%、地区数字税 5%–20%、货币转换费 | 当前登录账号 | 只买几十到几百颗、要发票、不想碰加密钱包 |

价格之外的差别在于手续复杂度。内购点两下就完事，退款走商店；Fragment 要钱包和地址，退款基本不存在；第三方只需要一个用户名，但服务商是谁、跑不跑路，得你自己核。

## 退款这件事，比你想的麻烦

Telegram 官方条款写得很直白：它不处理星星的购买交易，购买相关的任何问题都要找对应的支付处理方。换句话说，通过 App Store 买的找 Apple，通过 Google Play 买的找 Google，通过第三方机器人买的找那家服务商，Telegram 客服不管这一段。

数字商品的纠纷，退款权限在卖家手里。机器人或频道所有者可以通过 API 方法 refundStarPayment 把星星退给你，前提是他愿意。你付的钱进了谁的口袋，就只能找谁。

## 如果你是创作者或开发者

靠内容赚到的星星不能立刻变现。每笔收入有 21 天冻结期，之后才能在 Fragment 上用频道或机器人的所有者账号登录，绑定 TON 钱包（Tonkeeper、Telegram Wallet 之类），点 Convert to Toncoin 确认兑换。Telegram 对创作者兑换不收佣金，只收链上网络费，通常低于 $0.10。

开发者接 Stars 支付时最常撞的报错是 `Bad Request: STARS_FROM_AMOUNT_MISMATCH`，成因有三个：币种填 XTR 时 `amount` 要按整颗星星计，100 颗就写 `100`，照着美元习惯写成 `10000` 会直接报错；`provider_token` 必须是空字符串，填了第三方收单方的 token 就过不了校验；所有 `LabeledPrice` 的金额之和必须严格等于发票总额。
